# 🎓 Student Information System (Java)

## 📌 Project Overview

The Student Information System is a console-based Java application that allows users to manage student records efficiently. The system supports adding, viewing, searching, updating, and deleting student details.

## 🎯 Objectives

* Learn Java basics (OOP, Scanner, ArrayList)
* Implement CRUD operations
* Practice input validation and error handling
* Build a menu-driven console application

## 🛠️ Features

* Add new student
* View all students
* Search student by ID or name
* Update student details
* Delete student record
* Input validation (age & grade)

## ⚙️ Technologies Used

* Java
* JDK
* ArrayList
* Scanner class

## ▶️ How to Run

1. Install JDK
2. Compile the program:

   ```
   javac StudentInformationSystem.java
   ```
3. Run the program:

   ```
   java StudentInformationSystem
   ```
